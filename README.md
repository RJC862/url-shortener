# What it does
Simply allows users to shorten long URLs into sharable, easy-to-read URLs.

### 1. Backend & API Services
* **Spring Boot Framework:** Developed a high-performance, scalable RESTful backend service utilizing Java to handle business logic, routing, and data processing.
* **Relational Database Management:** Integrated PostgreSQL to securely store, query, and manage relational application data with strong data integrity.

### 2. Frontend Interface
* **Responsive UI:** Designed a clean, interactive user interface using HTML5, CSS3, and modern JavaScript/TypeScript to deliver a seamless user experience across devices.

### 3. DevOps, Containerization & CI/CD
* **Docker Containerization:** Packaged the application into isolated containers, ensuring environment consistency from local development to production deployment.
* **Jenkins Automation (CI/CD):** Configured Jenkins build pipelines to automate testing, integration, and deployment workflows upon code commits.

* **Backend Frameworks:** Spring Boot
* **Databases:** PostgreSQL
